# 白板(CleanSlate)

一个基于Python的命令行 C 盘清理工具，绿色免安装(如果你想的话同时也提供安装包)

## 为什么叫“白板”

清理完硬盘后，系统盘就像一块全新的白板(但不是直接格式化哈)

## 安装与运行

同时提供压缩包和安装包，解压或安装完直接运行clsl.exe文件即可运行。源码主入口为main.py(因为作者木有马内买服务器所以大家只能手动更新本软件了TAT)
*如遇执行失败报错可尝试以管理员运行此软件
*源码运行无需额外pip新的Python库
*源码运行需Python 3.11及以上稳定版本的解释器，推荐Python 3.14.6 解释器最稳定(因为开发环境是这个)
