# 白板(CleanSlate)
一个基于Python的命令行 C 盘清理工具，绿色免安装
* 零阑工坊开发

## 为什么叫“白板”
清理完硬盘后，系统盘就像一块全新的白板(但不是直接格式化哈)

## 重要风险提示
1. 部分高危删除功能，考虑普通用户有误删风险，相关函数已做注释封存，待交互方案完善后再启用。
2. **唯一官方下载渠道为 GitHub Releases，其他站点分发的程序不做安全保障，请务必谨慎使用!**
3. 项目不支持Linux或MacOS等系统，同时**不兼容Windows 32位**，完美兼容Win10 64位及以上系统

## 安装与运行
1. 下载 `CleanSlate_noSetup_v1.0.4.zip`，源代码下载`source code(zip)`或`source code(tar.gz)`
2. 解压后直接运行`clsl.exe`文件即可运行。
3. 源码主入口为`Oadmin.py`(需pyyaml库)

### 快速开始
程序启动自动扫描，输入2进入一键安全清理模式，确认输入`y`即可执行清理。

## 常见问题
* 为什么用yaml而不是json或者ini，json不支持注释，不方便用户查看，ini是一样的道理，另外，对于这俩货来说，yaml可读性属实比他俩高多了
* 如遇执行失败报错可尝试以管理员运行此软件
* 源码运行需pyyaml库以便读取yaml配置文件，安装命令：`pip install pyyaml`
* 源码及工具运行需Python 3.11及以上稳定版本的解释器，推荐Python 3.12 解释器最稳定(因为开发环境是这个)
* 补丁打包解包工具一律不提供exe版本，需要使用者自行配置Python环境
* 本软件暂不支持GUI界面，后续版本再做规划
