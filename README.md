
# 白板(CleanSlate)

一个基于Python的命令行 C 盘清理工具，绿色免安装
* 零阑工坊开发

## 为什么叫“白板”

清理完硬盘后，系统盘就像一块全新的白板(但不是直接格式化哈)

## 安装与运行

1. 下载 `CleanSlate_noSetup_v1.0.4.zip` 或运行 `CleanSlate_Setup_v1.0.4.exe`(源代码请下载`source code(zip)`或`source code(tar.gz)`)
2. 解压或安装完直接运行`clsl.exe`文件即可运行。
3. 源码主入口为`Oadmin.py`

### 快速开始
启动程序后会自动进行扫描，扫描完成在交互式窗口中输入2进入一键安全清理模式，确认并输入y，即可完成快速开始

## 常见问题
* 为什么用yaml而不是json或者ini，json不支持注释，不方便用户查看，ini是一样的道理，另外，对于这俩货来说，yaml可读性属实比他俩高多了
* 如遇执行失败报错可尝试以管理员运行此软件
* 源码运行需pyyaml库以便读取yaml配置文件（什么？？？你不会装？“pip install pyyaml”用去吧不用谢 （ ˙³˙））
* 源码及工具运行需Python 3.11及以上稳定版本的解释器，推荐Python 3.12 解释器最稳定(因为开发环境是这个)
* 补丁打包解包工具一律不提供exe版本，想用自己装Python去(ᗜ ˰ ᗜ) 
* 哦对了，本软件不支持GUI（以后再打算），不要再问是不是作者不会写了！(＊｀д´)

## 当前版本（正式版）

CleanSlate-v1.0.4-正式版，优化配置文件生成＆读取逻辑，程序加入客户端版本显示（虽然可能没有什么用处吧）。不再支持安装包版本，只保留绿色安装渠道。exe程序目前稳定可执行清理工作，支持补丁系统。目前整个软件目录至多占用25MB，源码82KB,生成的配置文件目前仅有2KB

**当前版本适用于 Windows 10 64 位 及更高版本**
